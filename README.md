# Site Kart Indoor

Site estático pronto para publicar no GitHub + Netlify.

## Arquivos
- `index.html` — estrutura da página
- `style.css` — visual responsivo
- `script.js` — menu mobile
- `assets/logo.png` — logo enviada

## Antes de publicar
1. Abra `index.html` e troque `contato@seukart.com.br` pelo e-mail real.
2. Se quiser, altere textos, preços, endereço, telefone e links.
3. Envie toda a pasta para um repositório do GitHub.

## Netlify
No Netlify:
1. Add new project / Import an existing project
2. Escolha GitHub
3. Selecione o repositório
4. Build command: deixe vazio
5. Publish directory: `.`
6. Clique em Deploy

Como é um site HTML/CSS/JS puro, não precisa de Node ou build.
